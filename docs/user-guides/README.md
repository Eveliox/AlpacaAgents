# AlpacaAgent user guides

Prepared September 18, 2026 against local source revision `235b087`.

Start with **AlpacaAgent-Complete-Guide.pdf** for all three volumes, or read them separately:

1. **01-operator-handbook.pdf** — setup, dashboard modes, research, shadow testing, paper operation, exits, and daily routine.
2. **02-use-cases-and-prompts.pdf** — worked workflows, agent prompts, examples, and printable review templates.
3. **03-command-and-recovery-reference.pdf** — commands, troubleshooting, recovery, files, terminology, and sources.

The PDFs include linked contents and bookmarks. Page numbers restart in each volume within the combined edition.

These guides document the current implementation. They correct several obsolete commands and descriptions in older project notes; no application behavior or trading permissions were changed to create them.

Editable content and the PDF builder are in `../guide-build/`. The builder requires ReportLab, pypdf, Pillow, and pypdfium2 for visual QA, plus the Windows Segoe UI and Consolas fonts.
